# Dados

O arquivo `raw/students_performance.csv` contém a base usada no projeto.

Durante a execução, o código cria em memória:

- `average score`: média simples de matemática, leitura e escrita;
- `passed_all_60`: indicador didático de nota >= 60 nas três áreas.

Nenhuma categoria original é renomeada ou reinterpretada.
